## About

I'm a founder and full-stack engineer based in Vadodara, India. I build **Craftorā** — a
marketplace for developers — and **Studioo**, a next-generation visual web builder that
turns intent into production-grade interfaces.

Most of my work sits at the intersection of product, engineering, and design: shipping
tools that other builders reach for daily, and caring about the last five percent of
polish that most software never gets.

<!-- ─── PHILOSOPHY ────────────────────────────────────────────────────────── -->

## Tech Philosophy

Good software disappears. It loads instantly, behaves predictably, and never asks the
user to think about it. I optimize for **developer experience** first — because the tools
a team uses shape everything they ship — then for **performance**, treating milliseconds
as a product feature rather than an afterthought.

**Beautiful UI** is not decoration; it is clarity made visible. And systems should be
built to **scale** while staying **simple** — the hardest constraint of all, and the one
worth defending.
